## 任务目标
查询指定用户的保单信息，支持按保单号精确查询或查询全部有效保单，并以结构化的 Markdown 格式返回结果。

## 输入参数

| 参数名 | 类型 | 必填 | 描述 |
|--------|------|------|------|
| userId | string | 是 | 用户唯一标识 |
| policyNo | string | 否 | 保单号，用于精确查询特定保单 |
| status | string | 否 | 保单状态筛选：all 查询全部，默认仅查询有效保单 |

## 输出格式

### 成功响应

返回结构化 Markdown 文本，包含以下信息：
- 查询成功提示及保单总数
- 每份保单的详细信息（保单号、产品名称、保险公司、保障额度、年缴保费、生效日期、到期日期、状态）
- 保单号需进行脱敏处理，仅显示首尾字符

### 失败响应

返回包含错误代码和提示信息的 Markdown 文本：
- 用户未找到：提示用户 ID 不能为空
- 无保单信息：提示未找到保单
- 系统错误：提示系统繁忙

## 执行流程

1. 验证用户 ID 是否为空，为空则返回错误
2. 根据输入参数决定查询策略：
   - 提供保单号：精确查询指定保单
   - status=all：查询用户全部保单
   - 无其他参数：查询用户有效保单
3. 对查询结果进行数据脱敏处理
4. 格式化为 Markdown 文本返回

## 数据脱敏规则

| 字段 | 脱敏规则 | 示例 |
|------|----------|------|
| 保单号 | 保留首尾各2位，中间用****替代 | AB****XY |
| 身份证号 | 保留前6位后4位，中间用********替代 | 110101********1234 |
| 手机号 | 保留前3位后4位，中间用****替代 | 138****5678 |
| 邮箱 | 保留首字符和@后部分，中间用****替代 | a****@example.com |

## 保单状态映射

| 状态值 | 显示文本 |
|--------|----------|
| active | 生效中 |
| expired | 已过期 |
| pending | 待生效 |
| cancelled | 已取消 |
| 其他 | 原值显示 |

## 注意事项
- 保单号脱敏是强制要求，不可返回完整保单号
- 金额为 null 时显示 0.00
- 日期为 null 时显示"终身"
- 保单列表为空时返回错误响应而非空列表

# HealthAgent 内网穿透方案

> 将本地 Spring Boot (8084) + Vue (5173) 项目暴露到公网访问

## 方案对比

| 特性 | Cloudflare Tunnel | cpolar | ngrok |
|------|------------------|--------|-------|
| **费用** | 完全免费 | 免费版可用 | 免费版可用 |
| **注册** | 可不登录（快速隧道） | 需注册 | 需注册 |
| **带宽** | 无限制 | 1Mbps | 无限制 |
| **流量** | 无限制 | 无限制 | 无限制 |
| **隧道数** | 无限制 | 4条 | 1个在线进程 |
| **域名** | 随机子域名 | 随机子域名(24h变) | 随机子域名 |
| **国内速度** | 中等（走Cloudflare节点） | 快（国内服务器） | 中等 |
| **稳定性** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| **推荐度** | 🥇 首选 | 🥈 国内备选 | 🥉 临时备选 |

## 方案一：Cloudflare Tunnel（推荐）

### 特点
- 完全免费，无带宽/流量限制
- 无需注册即可使用快速隧道
- 全球 CDN 节点加速
- 支持自定义域名（需登录）

### 安装

```powershell
# Windows（推荐 winget）
winget install Cloudflare.cloudflared

# 或手动下载
# https://github.com/cloudflare/cloudflared/releases
# 下载 cloudflared-windows-amd64.msi
```

### 快速启动（无需登录）

**方式 A：一键脚本**

```powershell
cd C:\Project\Code\HealthAgent\backend\src\main\resources\scripts
.\start-cloudflared.bat
```

**方式 B：手动命令**

```powershell
# 终端1 - 穿透后端
cloudflared tunnel --url http://localhost:8084

# 终端2 - 穿透前端
cloudflared tunnel --url http://localhost:5173
```

启动后终端会显示类似地址：
```
https://random-words-xxx.trycloudflare.com
```

### 自定义域名（需登录，长期使用推荐）

```powershell
# 1. 登录 Cloudflare
cloudflared tunnel login

# 2. 创建隧道
cloudflared tunnel create healthagent

# 3. 配置 DNS
cloudflared tunnel route dns healthagent api.yourdomain.com
cloudflared tunnel route dns healthagent app.yourdomain.com

# 4. 创建配置文件 ~/.cloudflared/config.yml
```

```yaml
tunnel: healthagent
credentials-file: ~/.cloudflared/<tunnel-id>.json

ingress:
  - hostname: api.yourdomain.com
    service: http://localhost:8084
  - hostname: app.yourdomain.com
    service: http://localhost:5173
  - service: http_status:404
```

```powershell
# 5. 启动隧道
cloudflared tunnel run healthagent
```

## 方案二：cpolar（国内访问最快）

### 特点
- 国内服务器，访问延迟低
- 免费版 4 条隧道、1M 带宽、不限流量
- 免费域名 24 小时变化
- 图形化管理后台

### 安装

```powershell
# 1. 下载安装包
# https://www.cpolar.com/
# 下载 Windows 版本，双击安装

# 2. 注册账号
# https://dashboard.cpolar.com/signup

# 3. 认证
cpolar authtoken <你的authtoken>
```

### 启动

**方式 A：一键脚本**

```powershell
cd C:\Project\Code\HealthAgent\backend\src\main\resources\scripts
.\start-cpolar.bat
```

**方式 B：手动命令**

```powershell
# 终端1 - 穿透后端
cpolar http 8084

# 终端2 - 穿透前端
cpolar http 5173
```

管理后台：http://localhost:9200

地址格式：`https://xxx.r1.cpolar.top`

## 方案三：ngrok

### 特点
- 老牌工具，生态成熟
- 免费版 1 个在线进程，每进程 1 个域名
- 40 连接/分钟限制
- 需注册

### 安装

```powershell
# Windows
winget install Ngrok.Ngrok

# 或
choco install ngrok

# 注册 & 认证
# https://dashboard.ngrok.com/signup
ngrok config add-authtoken <你的token>
```

### 启动

```powershell
# 终端1 - 穿透后端
ngrok http 8084

# 终端2 - 穿透前端
ngrok http 5173
```

管理后台：http://localhost:4040

地址格式：`https://xxxx.ngrok-free.app`

## 🔧 前后端配置调整（重要！）

穿透启动后，需要修改两个配置才能正常使用：

### 1. 前端 API 代理

当前 `vite.config.ts` 通过代理将 `/api` 转发到 `localhost:8084`，
公网访问时前端域名变了，代理规则失效。

**解决方案 A：环境变量注入后端公网地址（推荐）**

```typescript
// vite.config.ts
server: {
  proxy: {
    '/api': {
      // 优先使用环境变量指定的后端地址
      target: process.env.VITE_API_URL || 'http://localhost:8084',
      changeOrigin: true,
    },
  },
},
```

启动前端时注入公网地址：
```powershell
$env:VITE_API_URL="https://xxx.trycloudflare.com"
npm run dev
```

**解决方案 B：只穿透后端，前端打包放入 Spring Boot（最简）**

```powershell
# 1. 构建前端
cd frontend
npm run build

# 2. 复制到后端静态资源目录
xcopy /E /I dist\* ..\backend\src\main\resources\static\

# 3. 只穿透后端一个端口
cloudflared tunnel --url http://localhost:8084
```

后端自动托管前端静态文件，只需穿透一个端口。

### 2. CORS 跨域

后端 `WebConfig.java` 的 `allowedOrigins` 需要加入前端公网域名：

```java
// 方式1：直接修改代码（不推荐）
.allowedOrigins("http://localhost:5173", "https://xxx.trycloudflare.com")

// 方式2：通过配置文件（推荐）
@Value("${healthagent.cors.allowed-origins}")
private String[] allowedOrigins;
```

在 `application.yml` 中：
```yaml
healthagent:
  cors:
    allowed-origins: http://localhost:5173,http://localhost:5174,https://your-frontend.trycloudflare.com
```

或通过环境变量（不改源码）：
```powershell
$env:HEALTHAGENT_CORS_ORIGINS="https://xxx.trycloudflare.com"
java -jar app.jar
```

## 📋 完整启动步骤（Cloudflare 方案为例）

```powershell
# 1. 启动后端
cd C:\Project\Code\HealthAgent\backend
mvn spring-boot:run

# 2. 启动前端（设置后端公网地址）
cd C:\Project\Code\HealthAgent\frontend
$env:VITE_API_URL="https://后端公网地址.trycloudflare.com"
npm run dev

# 3. 启动穿透
cloudflared tunnel --url http://localhost:8084    # 终端1，记录后端公网地址
cloudflared tunnel --url http://localhost:5173    # 终端2，获得前端公网地址

# 4. 修改 CORS 配置，添加前端公网地址到 allowedOrigins
# 5. 重启后端使 CORS 生效
```

## ⚠️ 安全提醒

- 免费穿透的公网地址是公开的，任何人都可以访问
- 生产环境务必开启认证拦截器：`healthagent.auth.interceptor-enabled=true`
- 修改默认密码，不要使用 `admin/admin123`
- API Key 不要硬编码，使用环境变量
- 穿透用完及时关闭

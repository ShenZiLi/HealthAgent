## **1. 项目概述**

本项目旨在为用户提供一款轻量化、沉浸式的健康服务智能助手，以 H5 页面形式实现，支持语音和文字两种交互方式。通过对接现有系统 API，提供保单查询、体检预约等核心功能，并集成 AI 大模型进行意图识别与智能响应。

------

### 2.4 前端技术栈

| 组件         | 版本 | 用途                                                         |
| ------------ | ---- | ------------------------------------------------------------ |
| React        | 18   | 核心 UI 库，支持并发渲染、Suspense、自动批处理等新特性       |
| TypeScript   | ≥5.0 | 静态类型检查，提升代码健壮性与开发体验                       |
| Vite         | ≥5.0 | 极速构建与热更新，基于原生 ES 模块，开发体验优于 Webpack     |
| Ant Design   |      | 提供高质量企业级 UI 组件（如 Card、Form、Modal、Button），快速搭建保单卡片、预约表单等界面 |
| Tailwind CSS |      | 原子化 CSS 框架，用于定制布局、间距、响应式设计，与 Ant Design 互补（Ant 负责组件，Tailwind 负责容器/排版） |
| Zustand      |      | 轻量级全局状态管理，替代 Redux。用于管理： - 用户认证状态（token、userInfo） - 当前对话会话（conversationId、messages） - 语音识别状态（listening、transcript） - 流程图编辑状态（仅在管理后台使用） |

| 语音交互     |      | 原生 **Web Speech API**（`SpeechRecognition` + `SpeechSynthesis`），通过自定义 Hook 封装（如 `useVoiceInput()`） |
